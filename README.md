# EntryKit

A production-ready, unopinionated authentication UI package for Flutter.
Decouples UI from Logic, allowing you to use any backend (Firebase, AWS, Supabase, REST) by simply implementing a contract.

## Features

* ✅ **Pre-built UI:** Login, Sign Up, and Forgot Password screens.
* ✅ **State Management:** Built-in logic using `flutter_bloc`.
* ✅ **Social Auth:** Support for Google and Apple Sign In buttons.
* ✅ **Validation:** Configurable password complexity rules.
* ✅ **Theming:** Full control over colors, fonts, and input styles.
* ✅ **Internationalization:** All text strings are replaceable.
